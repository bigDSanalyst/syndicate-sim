# feedback-grape: A JAX-based Python Package for GPU-Accelerated GRAPE with Feedback

## Abstract

> Modern quantum technology applications require accurate control of quantum systems, including a
> feedback loop in the control process. While open-loop control can be performed using well
> established gradient methods like GRadient Ascent Pulse Engineering (GRAPE), it was until
> recently unclear how to combine these with feedback from measurements, which are inherently non-
> differentiable. Recent work has successfully demonstrated how feedback can be incorporated into
> GRAPE using machine learning, resolving this issue. Following this progress, we have developed
> an efficient Python package implementing the method of ``feedback GRAPE''. In this hands-on
> tutorial, we discuss the package in detail based on concrete examples. Built on the GPU-
> accelerated JAX platform, our package offers a user-friendly interface inspired by the widely-
> used QuTiP library, including simplified treatment of multi-component systems.
