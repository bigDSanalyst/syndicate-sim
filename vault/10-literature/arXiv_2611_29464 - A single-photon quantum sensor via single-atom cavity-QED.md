# A single-photon quantum sensor via single-atom cavity-QED

## Abstract

> We describe a cavity-QED sensor using an optical probe with exactly one photon per pulse. This
> has a better sensitivity than a coherent pulse with the same average power when no global
> coherent phase reference is available. The sensor measurement is based on the estimation of the
> Raman-controlled absorption probability of a single-photon pulse. We use the Fock state master
> equation to determine the dynamics and performance of the Raman-controlled absorption of a
> single photon pulse and optimise the sensitivity using machine learning. Two examples are
> presented; (1) the target parameter is the detuning of the two-level system itself, and (2) the
> target parameters describe a remote reflecting cavity. In the second case, the scheme does not
> require a shared coherent phase reference.
